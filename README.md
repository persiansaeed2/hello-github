# SOLMAZ — اپلیکیشن ثبت مطالعه با تقویم شمسی

اپ اندروید بومی (Kotlin + Jetpack Compose) با نام **SOLMAZ** برای ثبت جلسه‌های مطالعه روی
**تقویم شمسی (جلالی)**. طراحی با تم **سفید + صورتی** و زبان بصری **macOS جدید (Liquid Glass)**:
سطوح نیمه‌شفاف، گوشه‌های نرم، سایه‌های محو صورتی و فونت وزیرمتن. آیکون اپ یک گل سفید هشت‌پر
با مرکز زرد روی زمینهٔ صورتی است که به‌صورت وکتور رسم شده و در همهٔ چگالی‌ها تیز می‌ماند.

## امکانات (تک‌صفحه)

اپ عمداً **یک صفحه** دارد: «امروز». کاربر فقط با همین صفحه کار می‌کند.

| عنصر | توضیح |
|---|---|
| **تاریخ** | تاریخ شمسی امروز، مثلاً «یکشنبه ۳ آبان ۱۴۰۵» |
| **خلاصه** | تعداد لغات امروز + «چند نوبت مرور» و «چند تازه» + شمارهٔ درس فعلی |
| **راهنمای رنگ** | 🔴 نوبت مرور • 🟢 تازه (هنوز نخوانده) • ⚪️ بعداً (با تاریخ مرور بعدی) |
| **فهرست لغات** | همهٔ لغات درس فعلی، هر کدام با نوار رنگی و برچسب: «تازه» / «مرور ۲» / «۱۲ آبان» |
| **اولویت** | اول لغات تازهٔ **درس جاری**، بعد مرورهای همان درس، بعد «مانده از قبل» (مرورهای درس‌های قبلی) |
| **شروع مرور** | ۱۰ لغت با همان ترتیب؛ کارت لغت → «نمایش معنی» → 🟢 بلدم / 🔴 بلد نبودم |
| **تلفظ** | 🔊 «تلفظ آلمانی» و 🔊 «تلفظ فارسی» (TTS آفلاین دستگاه) روی کارت؛ 🔊 آلمانی روی هر ردیف فهرست |
| **اسم کاربر** | اولین اجرا اسم را می‌پرسد و بعد «سلام <اسم> 👋» نشان می‌دهد |
| **هیچ لغت نخوانده نمی‌ماند** | چون تازه‌ها اول می‌آیند و درس بعدی وقتی باز می‌شود که همهٔ لغات درس قبل حداقل یک‌بار خوانده شده باشند |
| **قواعد جعبه‌ها** | 🟢 یک جعبه بالا (۱→۸ با فاصلهٔ ۱،۲،۴،۸،۱۶،۳۲،۶۴،۱۲۸ روز)، 🔴 برگشت به جعبهٔ ۱ و تکرار در همان دور |
| **درس به درس** | درس ۱ باز است؛ درس بعدی وقتی باز می‌شود که همهٔ لغات درس قبل حداقل یک 🟢 گرفته باشند |

داده‌ها محلی‌اند (SharedPreferences + JSON) و اپ به اینترنت نیاز ندارد. تقویم شمسی هم در
`model/JalaliDate.kt` آماده است و بعداً به‌عنوان یک مقصد جداگانه اضافه می‌شود.

## اجرا و ساخت

```bash
# نیازمندی: JDK 17 و Android SDK (platform 34 + build-tools 34.0.0)
# مسیر SDK را در local.properties بگذارید:  sdk.dir=/path/to/Android/sdk

./gradlew :app:testDebugUnitTest   # تست‌های تقویم شمسی روی JVM
./gradlew :app:assembleDebug       # ساخت APK دیباگ
# خروجی: app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

APK آمادهٔ نصب (دیباگ) در [`dist/solmaz-debug.apk`](dist/solmaz-debug.apk) هم موجود است:

```bash
adb install -r dist/solmaz-debug.apk
```

یا پروژه را با **Android Studio** باز کنید (File ▸ Open) و Run بزنید.

## تقویم شمسی

تبدیل تاریخ با ریاضی صحیح (بدون کتابخانهٔ اضافه) پیاده شده و با تست واحد اعتبارسنجی می‌شود:

* ۸ تاریخ مرجع (نوروز ۱۴۰۰/۱۴۰۳/۱۴۰۵، ۲۲ بهمن ۱۳۵۷، …) در هر دو جهت
* رفت‌وبرگشت **هر روزِ** یک بازهٔ ۲۰ ساله
* طول ماه‌ها، سال کبیسه (۱۴۰۳ کبیسه، ۱۴۰۴ نه)، شنبه‌اول بودن هفته و ارقام فارسی

## دادهٔ کتاب (وارد شده)  📚

کتاب: **Uni sicher – Wortschatzübungen für Fortgeschrittene**

* **۱۳۸۷ لغت** در **۲۶ درس** (واحدهای کتاب: `1.1` … `5.3`)
* هر درس اپ = یک واحد کتاب؛ ترتیب عددی درست (۴.۱۰ بعد از ۴.۹)
* سرلغت با حرف تعریف (`die Schulpflicht`) برای یادگیری جنس + تلفظ آلمانی
* ترجمهٔ فارسی از فیلد `fa` همان فایل

بازتولید (`app/src/main/assets/words.json`):

```bash
python3 tools/import_book.py                      # 1387 لغت
python3 tools/import_book.py --include-related    # + فرم‌های مرتبط (۳۴۱ مورد)
```

## آپلود لغات (CSV یا JSON)  ⬆️

هر کدام را داشتی، در پوشهٔ `reference/` آپلود کن:

* **CSV** → با `tools/csv_to_words_json.py` به JSON تبدیل می‌شود:
  ```bash
  python3 tools/csv_to_words_json.py reference/words.csv
  ```
  (جداکنندهٔ `,` `;` `Tab` خودکار، BOM و فایل cp1252 پشتیبانی می‌شود، ستون‌های آلمانی/انگلیسی/فارسی شناسایی می‌شوند)
* **JSON** → اگر کلیدهایش با parser جور باشد مستقیم استفاده می‌شود؛ وگرنه فقط یک mapper کوچک اضافه می‌کنم.

## جای فایل PDF کتاب  📄

فایل PDF را در `reference/` بگذار (اسم دلخواه، مثلاً `reference/book.pdf`) و بگو تا:

1. متنش را با `tools/pdf_text.py` استخراج کنم (بدون هیچ کتابخانهٔ بیرونی)،
2. لغت‌ها را جدا و به فارسی ترجمه کنم،
3. `app/src/main/assets/words.json` را بسازم و APK جدید بدهم.

> PDF باید متنی باشد (در PDF‑خوان بتوان متن را انتخاب کرد)؛ PDF اسکن‌شده به OCR نیاز دارد.

## جای فایل لغات  📚

فقط یک فایل، یک مسیر:

```
app/src/main/assets/words.json     ← فایل واقعی لغات را همین‌جا بگذار
app/src/main/assets/words.sample.json  ← دادهٔ نمونه (تا وقتی فایل واقعی نیامده)
```

اپ اول `words.json` را می‌خواند؛ اگر نبود، نمونه را نشان می‌دهد. بعد از گذاشتن فایل،
یک build لازم است (`./gradlew :app:assembleDebug`) — من APK را می‌سازم و می‌دهم.
نیازی به اینترنت یا دسترسی به حافظهٔ گوشی نیست؛ فایل داخل خود اپ بسته‌بندی می‌شود.

### قالب JSON

هر شکلی از این‌ها قبول است (parser خودش تشخیص می‌دهد):

```json
[
  { "word": "apple", "meaning": "سیب", "lesson": 1 },
  { "word": "book",  "meaning": "کتاب", "lesson": 1 }
]
```

```json
{ "lessons": [ { "number": 1, "words": [ { "word": "apple", "meaning": "سیب" } ] } ] }
```

```json
{ "lessons": { "1": [ { "word": "apple", "meaning": "سیب" } ] } }
```

قواعد مهم:

* کلیدهای جایگزین هم شناخته می‌شوند: `term/word/english/en` و `meaning/translation/persian/fa`
  و `lesson/dars/unit/chapter` و معادل‌های فارسی (`لغت`, `معنی`, `درس`)
* `lesson` می‌تواند عدد یا رشتهٔ عددی باشد؛ نبودنش یعنی درس ۱
* `id` اختیاری است؛ اگر نباشد از `L<درس>:<لغت>` ساخته می‌شود. **اگر دو لغت هم‌نام در یک درس
  داری، `id` بده تا پیشرفتشان قاطی نشود**
* ردیف ناقص (بدون لغت یا بدون معنی) فقط skip می‌شود، کل فایل خراب نمی‌شود
