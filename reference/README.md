# جای فایل PDF کتاب

فایل PDF را در همین پوشه آپلود کن، مثلاً:

```
reference/book.pdf
```

بعد فقط بنویس «آپلود شد» تا من متنش را دربیاورم، لغات را ترجمه کنم و
`app/src/main/assets/words.json` را بسازم.

نکته: PDF باید **متنی** باشد (یعنی در پی‌دی‌اف‌خوان بتوانی متن را انتخاب کنی).
اگر اسکن/عکس باشد، متن قابل استخراج نیست و به OCR نیاز دارد.
